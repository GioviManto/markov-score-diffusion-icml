# Figures for the hand-written paper (29 Oct 2026; five added 31 Oct)

Built by `tools/paper_figs/make_paper_figures.py`; every figure is regenerated by

    .venv/bin/python tools/paper_figs/make_paper_figures.py --layout onecol    # 5.5 in text block (NeurIPS-style)
    .venv/bin/python tools/paper_figs/make_paper_figures.py --layout twocol    # 3.25 in column, 6.75 in full (ICML / PR)

`onecol/` and `twocol/` differ only in the full-width figures; the single-panel ones are 3.25 in in both.

**Style.** The text font is Times and the math is Computer Modern, matching the NeurIPS and ICML bodies; use `--font cm`
if the template is set in Computer Modern. The other choices follow Jérôme (call of 29 Oct, 45:26–46:57):
- a box on every panel
- axis labels at 10 pt and ticks at 9 pt, about the body size
- minor ticks
- no grid
- markers for measurements, lines for closed forms

The two diagrams are also written as bare `.tikz` pictures for `\input` in the paper.
Panels carry (a), (b), (c) above their top-left corner.

Every figure passes the repository's save gate: no prose inside a chart, every symbol set as math.

**Width.** Include each figure at its own width so the type stays at its designed size:
`\includegraphics{fig_x.pdf}` with no `width=`, or `width=\textwidth` for the full-width figures.

The data are read only from the thesis generators (`Diffusion/Markov_Score_Diffusion/thesis/tools`, branch
`thesis-scientific-audit-fixes`) and their frozen outputs. Nothing was refitted.

**About `fig_value_of_structure`.** No rerun was needed. E02a's EM–BP (C = 8 mixture) and E03's six networks were
scored on the same `exp_31` test bundles: 16 seeds, N = 32, 128, 512, 2048, and all 384 network rows pair with an EM–BP
row on (seed, N, test-bundle hash). The script refuses to draw if one does not. The networks were trained by E03's
common recipe on the clean training chains.

Mean per-seed ratio, network / EM–BP, at N = 32, 128, 512, 2048:

| network | 32 | 128 | 512 | 2048 |
|---|---|---|---|---|
| global MLP | 5.79 | 7.95 | 7.88 | 9.85 |
| window CNN | 2.07 | 2.87 | 3.45 | 5.58 |
| BiGRU (best of six for N ≥ 128) | 2.22 | 2.45 | 2.24 | 2.83 |
| U-Net | 2.52 | 3.06 | 2.72 | 3.14 |
| transformer | 2.56 | 3.04 | 2.77 | 2.98 |
| TCN | 2.45 | 2.81 | 2.74 | 3.23 |

These replace the thesis and defence numbers (MLP 6.6–10.9×, CNN 2.3–6.1×). Those came from the archival `exp_07` and
`exp_31`, where each network had its own EM–BP runs. **The honest headline is the best network at each N: 2.1–2.8×** (the window CNN at N = 32, 2.07×; BiGRU
above, 2.24–2.83×).
