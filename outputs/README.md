# outputs/

| path | what | tracked? |
|---|---|---|
| `frozen/` | the 869 files the current manuscript cites, imported verbatim from the archival research package (byte-identical to the public snapshot, cluster user redacted in three params files; see `docs/legacy/REDACTIONS.md`) | yes (43 MB, plain git; no file above 5 MB) |
| `legacy-unfrozen/` | runs the manuscript reads but that were never certified (`exp_18` laptop rerun, `exp_07_certified_clean_*` for the Hellinger table, `exp_22` information, `exp_32/33` capacity, `exp_21` misspecification, `exp_16_cluster` generation). Each directory's `params*.json` says what provenance it has; the audit (`docs/CURRENT_STATE_AUDIT.md`, §2 and §9) says what it lacks | yes (9 MB) |
| `<experiment_id>/` | outputs of experiments registered in `docs/EXPERIMENT_REGISTRY.md`; every run directory carries `params_*.json` with commit, dirty-tree status, resolved config hash, seed, host, environment and timestamp, written by `experiments/common.py` | yes, if under 5 MB per file and listed in the registry |
| `scratch/` | anything else; gitignored | no |

Large raw outputs (per-chain traces above 5 MB, sample bundles) are not committed. They
are regenerated by the registered script and their SHA-256 is recorded in
`experiments/registry/<experiment_id>.json` so a regenerated copy can be checked.
