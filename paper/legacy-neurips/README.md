# Recovering Markov dynamics from noised sequences

LaTeX source of the paper *Recovering Markov dynamics from noised sequences:
tree-exact inference and transition learning* (NeurIPS format). The body
occupies pages 1–9; references begin on page 10 and the appendix follows.

The compiled document is [`main.pdf`](main.pdf).

## Summary

For sequences generated by a Markov chain and corrupted by the
variance-preserving diffusion channel, the posterior factor graph is a tree,
so one forward–backward sweep gives exact smoothing marginals — and, through
Fisher's identity, the exact E-step gradient at each parameter value. The
paper learns the transition law from noised data alone by EM around that
inference routine and compares it, at an equal number of clean trajectories,
with denoising score-matching networks under a common validation protocol.

The comparison is asymmetric in both directions, and the paper says so: the
estimator is given the Markov factorisation but sees one frozen noised
realisation per trajectory and never the clean signal, while the networks are
given no structure but do see the clean trajectories and redraw the diffusion
time and corrupting noise at every gradient step. The reported factor is
therefore value per clean trajectory under the two standard recipes, not a
ranking at a matched information interface.

## Building

Builds with [Tectonic](https://tectonic-typesetting.github.io/), which runs
BibTeX automatically:

```bash
tectonic main.tex
```

## Layout

| Path | Content |
| --- | --- |
| `main.tex` | the nine-page body, followed by references and the appendix input |
| `appendix.tex` | protocol, provenance, robustness and scope appendices |
| `sections/` | **generated** tables and number macros — do not hand-edit |
| `figures/` | the four figures (generated, Arial/TrueType) |
| `neurips_2023.sty` | the style the paper is set in |
| `references.bib` | bibliography, shared with the companion thesis |

Every number in `sections/` and every figure is produced by a script from
frozen experiment outputs in the research repository; rebuilding the PDF needs
only a TeX engine. The headline table is rendered by the same generator that
produces the thesis's copy, from one computation, so the two documents cannot
report the same cells differently.

The companion MSc thesis, which develops the exact-score theory at full
length, lives in its own repository (`markov-score-diffusion-thesis`).
